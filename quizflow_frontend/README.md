# QuizVK - frontend

React-приложение (Vite), обёртка вокруг `src/App.jsx`. Говорит с бэкендом
на Django (см. соседний проект `quizflow_backend`) через REST и
WebSocket, а также с отдельным AI-сервисом генерации квизов
(`quizflow_ai_service`) через обычный REST-запрос.

## Запуск

Нужен Node.js 18+.

```bash
cd quizflow_frontend
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Бэкенд при этом должен быть уже
запущен на `http://localhost:8000` (см. README бэкенда - `python manage.py
runserver` в отдельном терминале). Для генерации квизов через ИИ
дополнительно нужен запущенный `quizflow_ai_service` на `http://localhost:8100`
(см. его README) - без него всё остальное приложение работает как обычно,
недоступна будет только сама кнопка «Сгенерировать».

Если что-то из перечисленного крутится не на стандартном порте -
поменяйте `API_BASE`, `WS_BASE` и `AI_SERVICE_BASE` в самом начале
`src/App.jsx`.

## Как проверить, что всё связалось

1. Открой `localhost:5173` → «Регистрация» → создай организатора.
2. «Новый квиз» → заполни вопрос(ы) → «Запустить квиз» - попадёшь в лобби
   с настоящим кодом комнаты.
3. Открой это же `localhost:5173` в окне инкогнито (или другом браузере) →
   «Войти в квиз» → введи код и ник - второе окно появится в списке
   участников первого окна само, без обновления страницы.
4. В окне организатора - «Начать квиз»: оба окна должны одновременно
   увидеть первый вопрос.

Если на шаге 3 участник не появляется - почти наверняка бэкенд не
запущен или недоступен по `API_BASE`; проверьте консоль браузера (там же
будет видно, если WebSocket не подключился) и что `python manage.py
runserver` не упал с ошибкой.

## Сборка для продакшена

```bash
npm run build
```

Соберёт статику в `dist/` - раздавайте её через nginx/любой статический
хостинг, `API_BASE`/`WS_BASE`/`AI_SERVICE_BASE` в `src/App.jsx` при этом
надо поменять на адреса продакшен-бэкендов до сборки.
